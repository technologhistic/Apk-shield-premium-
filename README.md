# APK Shield Premium

A modern Android APK security scanner and malware analysis application with advanced local static rules and Gemini-powered AI threat analysis.

## Features
- **Security Dashboard**: Live dynamic security score radial gauge (0-100), threat threshold telemetry, real-time protection indicators, and rapid scanning capabilities.
- **Malware Scan Center**: Upload and audit standalone `.apk` files directly in-browser using full client-side parsing (manifest tokens, permission mapping, bytecode obfuscation checks, cryptographic MD5/SHA-1/SHA-256 certificate hashing), alongside an installed apps catalog with query and SDK filters.
- **Detailed Security Reports**: Complete static risk evaluation, 6 Advanced Premium Security Suite modules (Gemini AI Vulnerability Analysis, Malware Detection Engine, API Key & Secret Detection, Code Issue Locator with file traces, Automatic Fix Suggestions, and ProGuard/R8 Obfuscation Audits).
- **Mutual White-Shield Policy Protocol**: Strict automated whitelist bypass rules protecting official APK Shield applications (`com.aistudio.apkshieldpremium.qpxz`, `com.aistudio.apkshieldfree.qpxz`).
- **Scan History & Encrypted PDF Export**: Historical database log with single-click inspection and encrypted report dossier export.
- **Interactive Premium Command Center**: 7 dedicated interactive workspaces including live Gemini AI threat assessments, batch package sandbox scanning, encrypted PDF compilation, cloud backups, real-time protection simulator, and global CVE vulnerability database audits.
